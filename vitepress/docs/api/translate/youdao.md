# 有道翻译

:::info
# Pot 接入有道翻译 API 完整教程（可直接部署）
# 简介
本教程适用于为 Pot 划词翻译工具 配置官方有道在线翻译 API，解决纯离线词典翻译短句、长句不准的问题。
实现效果：离线词典（ECDICT）+ 有道在线翻译 双引擎共存，单词查释义、段落整句翻译兼顾。  
⚠️ 重要区分：本文对接的是 有道文本翻译 API，不是有道大模型，大模型密钥无法在 Pot 中使用。  
# 一、前期准备
- 已安装最新版 Pot 客户端
- 可正常联网（有道 API 为在线服务）
- 有道智云账号（个人免费额度足够日常使用）
二、有道智云后台配置（核心步骤）
1. 进入官方控制台
打开有道智云官网并登录：https://ai.youdao.com/
2. 开通文本翻译服务
控制台左侧找到并进入 文本翻译，点击开通服务，生成专属服务实例。  
❌ 禁止开通/选择「有道大模型」，与 Pot 插件不兼容。
3. 创建官方应用
进入应用管理，点击【创建应用】，严格按照以下参数填写：  
| 配置项 | 填写内容 |
| 接入方式 | API |  
| 应用描述 | 按需求填 | 
| 服务器IP | 留空（必填） |  
✅ IP留空原理：解除设备限制，允许本地电脑调用接口，填写固定IP会导致翻译失败。  
4. 绑定实例并获取密钥
5. 应用创建成功后，将第一步开通的 文本翻译实例 绑定至当前应用
6. 进入应用详情页，复制保存：App ID（应用ID）、App Key（应用密钥）
# 三、Pot 客户端配置有道翻译
1. 打开 Pot，依次进入：偏好设置 → 服务设置 → 翻译  
2. 点击【添加服务】，选择 有道翻译  
3. 填写配置信息：

  - 配置名称：有道翻译（可自定义）  
  - App ID：粘贴有道智云后台获取的应用ID  
  - Key：粘贴有道智云后台获取的应用密钥  
4. 点击保存，开启有道翻译服务开关  
5. 可拖动服务条目，调整翻译结果的展示优先级  
# 四、功能测试  
任意选中英文单词、短句、段落，触发 Pot 划词翻译，即可同时展示：  
- ECDICT 离线词典：精准单词音标、基础释义（无网络可用）  
- 有道在线翻译：通顺整句、段落翻译（联网可用）   
# 五、常见问题排查
1. 配置成功但无翻译结果  
检查是否选错服务、是否绑定文本翻译实例、密钥是否有多余空格、服务器IP是否留空。  
2. 调用报错/请求失败  
确认账户有道智云免费额度未耗尽，网络正常，未使用大模型密钥。  
3. 和离线词典冲突  
双服务可完美共存，互不冲突，推荐同时开启使用。  
六、计费说明  
- 有道智云新用户赠送免费字符额度，个人日常划词基本免费  
- 超额后按字符低价计费，可在控制台实时查看用量、控制成本
